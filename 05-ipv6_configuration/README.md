# Day 05 – IPv6

Three IPv6 labs completed while following Jeremy's CCNA course in Cisco Packet Tracer.

## What I configured

### Lab 1 – Dual Stack

* Enabled IPv6 routing on routers
* Configured IPv6 addresses on router interfaces
* Configured IPv6 addresses and default gateways on PCs
* Tested connectivity using both IPv4 and IPv6

### Lab 2 – EUI-64 and Static Routing

* Calculated EUI-64 interface IDs
* Configured IPv6 addresses using EUI-64
* Enabled IPv6 on interfaces
* Configured IPv6 static routes between networks

### Lab 3 – SLAAC and Backup Routing

* Used SLAAC to automatically assign IPv6 addresses to PCs
* Configured IPv6 static routes
* Implemented a backup path
* Tested failover using `ping` and `traceroute`

## Troubleshooting

During these labs I practiced troubleshooting by:

* Checking IPv6 addresses and prefixes
* Verifying default gateways
* Confirming routing tables
* Testing connectivity with `ping`
* Using `traceroute` to verify routing paths

## What I learned

Through these labs I gained hands-on experience with:

* IPv4/IPv6 dual-stack networks
* EUI-64
* SLAAC
* Link-local addresses
* IPv6 static routing
* Basic network troubleshooting

These labs helped me understand how IPv6 networks are configured and how connectivity problems can be identified and solved.
